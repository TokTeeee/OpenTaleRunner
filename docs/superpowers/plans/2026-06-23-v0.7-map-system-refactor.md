# 地图系统重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 重构地图系统：移除右侧面板地图TAB、统一坐标系、地点地图仅在玩家到达时可见

**Architecture:** 三级地图保持世界→区域→地点层级，但地点地图仅对玩家当前所在地点开放。所有位置用坐标表示。移除 EnvironmentInfo 面板中的地图 TAB，只保留 RightPanel 的全屏 MapModal 入口。

**Tech Stack:** TypeScript, Zustand, React, Canvas API, IndexedDB, Vitest

---

## 核心变更

1. **移除右侧面板地图TAB** — `EnvironmentInfo.tsx` 中的"地图"TAB 移除，`WorldMap.tsx` 改为纯按钮打开 MapModal
2. **统一坐标系** — 世界/区域/地点的位置统一用 `{ x, y }` 坐标，`RegionRef.worldX/worldY` 改为 `worldPos: { x, y }`，`LocationRef.regionX/regionY` 改为 `regionPos: { x, y }`
3. **地点地图访问控制** — `navigateToLocation` 检查玩家是否在该地点，不在则拒绝进入地点详情视图；世界/区域地图正常浏览
4. **玩家位置只在当前层级显示** — 世界地图显示玩家所在区域标记，区域地图显示玩家所在地点标记，地点地图显示玩家精确位置

- [ ] **Step 1: 在 mapStore 的 navigateToLocation 中添加访问控制**

只有当 `playerLocationId === locationId` 时才允许进入地点详情视图。否则只高亮该地点但停留在区域地图层级。

```typescript
navigateToLocation: async (locationId) => {
  const { playerLocationId } = get();
  // 只有玩家在当前地点时才能查看地点详情
  if (playerLocationId !== locationId) {
    // 仅高亮选中地点，不进入详情
    set({ selectedLocationId: locationId });
    return;
  }
  set({ viewLevel: 'location', currentLocationId: locationId, isLoadingLocation: true });
  try {
    const locationMap = await mapStorage.getLocationMap(locationId);
    set({ locationMap, isLoadingLocation: false });
  } catch {
    set({ isLoadingLocation: false });
  }
},
```

在 MapState 接口中添加 `selectedLocationId: string | null`。

- [ ] **Step 2: 更新 MapView — 移除 TAB 栏，只保留面包屑**

移除顶部的世界/区域/地点 TAB 切换栏，只保留面包屑导航。因为地点层级是自动的（玩家到达时才能看），不需要手动切换。

```tsx
export function MapView() {
  const { viewLevel, currentRegionId, currentLocationId, currentRegion, navigateBack, playerLocationId } = useMapStore();

  const breadcrumb = [];
  breadcrumb.push({ label: '世界', level: 'world' as MapViewLevel });
  if (currentRegionId && currentRegion) {
    breadcrumb.push({ label: currentRegion.name, level: 'region' as MapViewLevel });
  }
  if (currentLocationId && viewLevel === 'location') {
    const locName = currentRegion?.locations.find(l => l.id === currentLocationId)?.name ?? '地点';
    breadcrumb.push({ label: locName, level: 'location' as MapViewLevel });
  }

  return (
    <div className="flex flex-col h-full">
      {/* Breadcrumb only — no TAB bar */}
      {breadcrumb.length > 1 && (
        <div className="flex items-center gap-1 px-3 py-1.5 bg-white/[.02] border-b border-white/[.04] text-[10px]">
          {breadcrumb.map((item, i) => (
            <span key={i} className="flex items-center gap-1">
              {i > 0 && <span className="text-gray-600">›</span>}
              <button
                onClick={() => {
                  const state = useMapStore.getState();
                  if (item.level === 'world') {
                    if (state.viewLevel === 'location') navigateBack();
                    if (useMapStore.getState().viewLevel === 'region') navigateBack();
                  } else if (item.level === 'region') {
                    if (state.viewLevel === 'location') navigateBack();
                  }
                }}
                className={`${i === breadcrumb.length - 1 ? 'text-emerald-400' : 'text-gray-500 hover:text-gray-300'}`}
              >
                {item.label}
              </button>
            </span>
          ))}
        </div>
      )}

      {/* Map content */}
      <div className="flex-1 overflow-hidden">
        {viewLevel === 'world' && <WorldMapView />}
        {viewLevel === 'region' && <RegionMapView />}
        {viewLevel === 'location' && <LocationMapView />}
      </div>
    </div>
  );
}
```

```typescript
// Player marker at current location
if (playerLocationId) {
  const playerLoc = region.locations.find(l => l.id === playerLocationId);
  if (playerLoc) {
    const px = playerLoc.regionPos.x * tileSize + offsetX + tileSize / 2;
    const py = playerLoc.regionPos.y * tileSize + offsetY + tileSize / 2;
    // Glow
    const glow = ctx.createRadialGradient(px, py, 3, px, py, 15 * zoom);
    glow.addColorStop(0, PLAYER_MARKER.glow);
    glow.addColorStop(1, 'rgba(96,96,255,0)');
    ctx.fillStyle = glow;
    ctx.beginPath();
    ctx.arc(px, py, 15 * zoom, 0, Math.PI * 2);
    ctx.fill();
    // Dot
    ctx.fillStyle = PLAYER_MARKER.fill;
    ctx.beginPath();
    ctx.arc(px, py, 5 * zoom, 0, Math.PI * 2);
    ctx.fill();
    ctx.strokeStyle = PLAYER_MARKER.border;
    ctx.lineWidth = 2;
    ctx.stroke();
  }
}
```
