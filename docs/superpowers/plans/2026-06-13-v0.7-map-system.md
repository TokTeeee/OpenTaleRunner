# v0.7.x 地图系统 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现像素8-bit风格三级地图系统（世界地图 → 区域地图 → 地点地图），AI 背景 + 程序化瓦片混合渲染，IndexedDB 持久化，GM 推进位置更新。

**Architecture:** 三级地图层级，世界/区域用程序化瓦片，地点用 AI 背景 + 瓦片标注层。地图为纯展示参考工具，玩家通过 GM 文字交互移动。

**Tech Stack:** TypeScript, Zustand, React, Canvas API, IndexedDB (idb), Vitest
