# v0.6.4b 技能点系统 — 升级获得技能点，解锁职业技能 (Ability)

## 背景

v0.6.2 实现了 16 个 Ability (3 学派)，`learnAbility/forgetAbility` store 方法已存在，`checkCanLearn` 校验完整。但玩家无法在 UI 上主动学习技能，只能通过 debug 或 LLM 返回自动添加。

现有 TierUnlockModal 在 L5/L10/L15 自动弹窗选 1 个职业天赋节点 (ClassNode)，与技能点系统是并列关系。

## 目标

1. 每次升级 +1 技能点 (`unspentSkillPoints`)
2. ClassSkillTreeModal 增加「技能」TAB，展示当前职业可学的 Ability 列表
3. 点击未学 Ability → 校验 → 消耗 1 技能点 → 学习

## 设计

### 1. Character 类型新增 unspentSkillPoints

在 `types/character.ts` 的 `Character` 接口中追加：

```typescript
unspentSkillPoints: number;  // 0-20, 升级时 +1
```

### 2. grantExp 升级时 +1 技能点

修改 `services/level/grantExp.ts`，升级时同步 +1 `unspentSkillPoints`：

```typescript
// 升级时: unspentAttributePoints +1, unspentSkillPoints +1
return { level, exp: pool, unspentAttributePoints: unspentAttributePoints + (level - state.level), unspentSkillPoints: state.unspentSkillPoints + (level - state.level) };
```

同时更新 `ExpGrantInput` 和 `ExpGrantResult` 类型加入 `unspentSkillPoints`。

### 3. applyServerExpGrant 同步

修改 `characterStore.ts` 的 `applyServerExpGrant`，patch 中追加 `unspentSkillPoints`。

服务端 `exp_formula.py` 也需同步返回 `unspentSkillPoints`，但这是服务端改动，客户端先做本地计算。

### 4. characterStore 新增 learnAbilityWithPoint action

```typescript
learnAbilityWithPoint: (abilityId: string) => void;
```

逻辑：
1. `unspentSkillPoints <= 0` → no-op
2. `checkCanLearn` 校验不通过 → no-op
3. 已学 → no-op (幂等)
4. 通过 → `learnAbility(abilityId)` + `unspentSkillPoints - 1`

### 5. ClassSkillTreeModal TAB 切换

改造 `ClassSkillTreeModal`，顶部增加 TAB：

- **天赋** — 现有的 12 节点技能树 (ClassNode)，保持不变
- **技能** — 当前职业可学的 Ability 列表

「技能」TAB 内容：
- 按 `requirements.classes` 过滤当前职业可学的 Ability
- 已学的显示绿色 ✅ + 名称
- 未学的显示名称 + 属性/等级要求 + 「学习」按钮
- 学习按钮：`unspentSkillPoints > 0` 且 `checkCanLearn` 通过时可点击
- 不满足条件时按钮 disabled + 灰色提示原因

### 6. LevelBar 提示

在 LevelBar 中追加技能点提示：

```tsx
{unspentSkillPoints > 0 && (
  <div className="mt-1 text-[10px] text-purple-300/80">
    🔮 {unspentSkillPoints} 个技能点待分配
  </div>
)}
```
