# v0.7.x 地图系统 — 像素8-bit三级地图

> **日期:** 2026-06-13
> **版本:** v0.7.x
> **前置:** v0.6.x (战斗/属性/技能系统)

## 1. 目标

在游戏客户端内实现像素8-bit风格地图系统，作为**信息展示面板**（非交互入口），供玩家参考当前世界/区域/地点信息，配合 GM 文字交互推进位置变化。

## 2. 核心设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 渲染方式 | 混合方案：AI 背景 + 程序化瓦片层 | 背景保证视觉独特性，瓦片层保证标注精确性 |
| 地图层级 | 三级：世界地图 → 区域地图 → 地点地图 | 世界→大区域→具体地点，符合 TRPG 探索逻辑 |
| 数据持久化 | IndexedDB（客户端） | 大容量存图片 Blob + 结构数据，离线可用 |
| AI 生成时机 | 玩家首次进入时按需生成 | 只生成去过的地区，节省资源 |
| 世界地图风格 | 像素点阵式（Dragon Quest 风格） | 经典8-bit感，格子化便于程序化生成 |
| 交互模式 | 纯展示参考，GM 推进位置 | 符合文字交互为主的 TRPG 体验 |
| 图片 API | 可配置端点 + API KEY | 灵活支持不同 AI 图片生成服务 |

## 3. 三级地图结构

```
世界地图 (World Map)
├── 翡翠王国 (Region)
│   ├── 翡翠城 (Location - 主城) ← AI背景 + 建筑/NPC标注
│   ├── 河谷村 (Location - 村庄) ← AI背景 + 建筑/NPC标注
│   ├── 翡翠平原 (Location - 野外) ← AI背景
│   └── 银峰山 (Location - 山岭) ← AI背景
├── 北境荒原 (Region)
│   ├── 冰霜堡 (Location - 主城)
│   └── ...
└── ...
```

### 3.1 世界地图 (World Map)

- **渲染**: 程序化像素点阵，瓦片网格
- **内容**: 大陆轮廓、海洋、山脉、大区域标注
- **交互**: 点击已发现区域 → 切换到区域地图
- **生成**: 故事书 seed → 程序化生成瓦片网格 → 标注区域点

### 3.2 区域地图 (Region Map)

- **渲染**: 程序化像素瓦片（继承世界地图地形信息）
- **内容**: 区域内地点分布（主城、村庄、野外、地下城等）
- **交互**: 点击已发现地点 → 切换到地点地图
- **生成**: 基于世界地图区域信息 → 程序化生成

### 3.3 地点地图 (Location Map)

- **渲染**: AI 生成背景图 + 程序化瓦片标注层叠加
- **内容**: 建筑、NPC、地标、玩家位置
- **交互**: 纯展示，无点击交互
- **生成**: 首次进入时 → GM 生成 prompt → 调用 AI 图片 API → 存 IndexedDB

## 4. 数据模型

```typescript
// ===== 世界地图 =====
interface WorldMapData {
  id: string;              // 基于故事书 seed
  width: number;           // 格子数
  height: number;
  tiles: WorldTile[][];    // 地形瓦片
  regions: RegionRef[];    // 可进入的区域
  playerPos: { regionId: string }; // 玩家所在区域
  generatedAt: number;
}

type WorldTileType = 'ocean' | 'plains' | 'forest' | 'mountain' | 'desert' | 'snow' | 'swamp';

interface WorldTile {
  type: WorldTileType;
  regionId?: string;       // 该格子属于哪个区域
}

// ===== 区域引用（世界地图上的点）=====
interface RegionRef {
  id: string;
  name: string;
  type: 'kingdom' | 'wasteland' | 'frontier' | 'island';
  worldX: number;
  worldY: number;
  climate: string;         // 继承自世界地图地形
  terrain: string;
  discovered: boolean;
  locations: LocationRef[];
}

// ===== 地点引用（区域地图上的点）=====
interface LocationRef {
  id: string;
  name: string;
  type: 'capital' | 'town' | 'village' | 'dungeon' | 'wilderness' | 'mountain' | 'forest';
  regionX: number;
  regionY: number;
  discovered: boolean;
}

// ===== 地点地图 =====
interface LocationMapData {
  id: string;              // 与 LocationRef.id 对应
  name: string;
  type: LocationRef['type'];
  backgroundImageKey: string; // IndexedDB 中的 Blob key
  buildings: MapBuilding[];
  npcs: MapNPC[];
  landmarks: MapLandmark[];
  playerPos: { x: number; y: number };
  generatedAt: number;
}

interface MapBuilding {
  id: string;
  type: 'guild' | 'blacksmith' | 'shop' | 'inn' | 'temple' | 'house' | 'landmark';
  name: string;
  tileX: number;
  tileY: number;
  width: number;
  height: number;
  npcIds: string[];        // 建筑内 NPC
}

interface MapNPC {
  id: string;
  name: string;
  buildingId: string | null; // null = 户外
  tileX: number;
  tileY: number;
  spriteType: string;
}

interface MapLandmark {
  id: string;
  name: string;
  tileX: number;
  tileY: number;
  description: string;
}
```

## 5. 生成流程

### 5.1 世界地图生成

```
故事书内容 → 提取 seed + 区域信息
  → 程序化生成瓦片网格 (noise + biome rules)
  → 标注区域点 (RegionRef[])
  → 存入 IndexedDB
```

### 5.2 区域地图生成

```
RegionRef (气候/地形/类型)
  → 程序化生成区域瓦片网格
  → 标注地点点 (LocationRef[])
  → 存入 IndexedDB
```

### 5.3 地点地图生成（首次进入时）

```
玩家首次进入地点
  → 检查 IndexedDB 是否已存在
  → 不存在则:
    1. 从 LocationRef 获取类型/气候/地形
    2. GM 生成结构化 prompt (建筑布局 + NPC 位置)
    3. 调用配置的图片 API 生成像素8-bit背景图
    4. 结构数据 + 背景图 Blob 存入 IndexedDB
  → 渲染: 背景图 + 瓦片层叠加建筑/NPC/玩家标注
```

## 6. 位置更新机制

地图是参考工具，玩家位置由 GM 推进：

```
玩家: "我前往铁匠铺"
  ↓
GM: 解析意图 → 输出结构化位置变更
  ↓
mapStore: 更新 playerPos → 地图面板自动刷新标记
  ↓
玩家: 打开地图 → 看到自己已在铁匠铺内
```

GM 输出的位置变更格式（需在 GM prompt 中约定）：
```json
{
  "locationChange": {
    "type": "building",
    "buildingId": "blacksmith_01",
    "description": "你推开了铁匠铺厚重的木门"
  }
}
```

| `RegionMapView` | `components/map/RegionMapView.tsx` | 区域地图渲染组件 |
| `LocationMapView` | `components/map/LocationMapView.tsx` | 地点地图渲染组件 |

## 9. UI 布局

- 主界面底部导航栏增加"地图"按钮
- 地图视图顶部 TAB 栏：世界地图 | 区域地图 | 地点地图
- TAB 栏下方显示当前层级路径：`翡翠王国 > 翡翠城`
- 世界/区域地图：Canvas 渲染像素瓦片 + 区域/地点名称标注
- 地点地图：AI 背景图 + 叠加瓦片标注层（建筑图标、NPC 图标、玩家闪烁点）
- 未发现的区域/地点显示为迷雾（暗色瓦片 + "?" 标记）

## 10. 扩展性考虑

- **迷雾系统**: 未探索区域用迷雾覆盖，探索后揭开
- **地图标记**: 玩家可自定义标记（"这里有宝箱"）
- **小地图**: 主界面角落显示当前地点小地图
- **天气叠加**: 地点地图上叠加天气效果（雨、雪）
- **传送点**: 后续可支持快速旅行标记
