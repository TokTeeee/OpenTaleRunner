# v0.5.14 — 角色创建 + CharacterPanel 体验修订

> 继承自：v0.5.13 (commit `9cb00da` + tag `v0.5.13`) 的 "character creation & panel" 用户体验反馈。
> 锁定日期：2026-06-07
> 单 PR 切片：v0.5.14 覆盖 4 个用户反馈点，**不重构**任何状态管理

---

## §0 背景

v0.5.13 完成 5-PR 清扫后，用户亲身体验 wizard 与 CharacterPanel 后提出 4 个修订：

1. **Wizard 步骤顺序** — 职业应在属性分配之后，PM 用职业+属性生成背景故事
2. **属性栏高度** — 当前 3 块（雷达图 + Vital Stats + 文字）占太多空间，最底被状态栏遮挡
3. **职业显示在角色姓名下** — 加 "职业：战士 ▼" 文字（无职业时显 "无职业"），可点击查看技能树
4. **职业技能与技能栏合并** — 当前 12 节点技能树独立 section 应与 `character.skills` 合并

---

## §1 设计目标

### 目标
- ✅ G1: 7 步重排 wizard，让 PM 在生成背景时能拿到职业 + 6 项属性
- ✅ G2: CharacterPanel 属性 section 高度从 ~250px 缩到 ~140px（雷达缩小）
- ✅ G3: 头部加 "种族：X，职业：Y" 显示行，职业可点击
- ✅ G4: 技能 chip 合并为 1 个 section，3 种颜色（蓝/绿/黄）

### 非目标（v0.6+ 范畴）
- ❌ 重新设计属性雷达图本身（形状/动画）
- ❌ 真正实现 SkillRegistry（v0.6+ 已规划）
- ❌ 多人创建时序调整

## §2 Wizard 7 步重排

### 当前 → 新顺序

| 步 | 旧位置 | 新位置 | 内容 | 验证 |
|----|--------|--------|------|------|
| 1 | Step 1 | Step 1 | 出生地 (village select) | villageId 非空 |
| 2 | **Step 6 (review)** | **Step 2 (新)** | 名字 + 外貌 (手动 + AI 按钮) | name 非空 (或留 AI 生成) |
| 3 | Step 3 | Step 3 | 属性 (3d6 + 滑块) | 6 项总和 = 78 ± 调整 |
| 4 | **Step 7 (末)** | **Step 4 (新)** | 职业 (4 职业 + T1 + 无职业) | classId+T1 或显式无职业 |
| 5 | Step 2 | **Step 5 (新)** | 背景 (PM 引导) | bgDone=true |
| 6 | Step 4 | Step 6 | 技能 (PM 生成 2-3) | skills.length>0 |
| 7 | Step 5 | Step 7 | 装备 (PM 生成初始) | equipmentSummary 非空 |
| — | Step 6 (review) | **删** | — | — |

### 关键实施
- `WIZARD_TOTAL_STEPS` 不变（= 7）
- `renderStep` switch case 重新映射：
  - `case 1`: 出生地 (原 case 1)
  - `case 2`: renderNameAppearance (新方法, 从 review 抽出)
  - `case 3`: 属性 (原 case 3)
  - `case 4`: 职业 (原 case 7, 内容不变)
  - `case 5`: 背景 (原 case 2)
  - `case 6`: 技能 (原 case 4)
  - `case 7`: 装备 (原 case 5)
- 删除 `renderReview()` 整段
- `canNext` 验证逻辑随 case 编号走 (case 1=village / case 2=name / case 3=attrs / case 4=class / case 5=bg / case 6=skills / case 7=equipment)

### 背景 Prompt 升级
**旧** prompt 输入: `{village, background hints}` (玩家在 Step 2 自由回答)
**新** prompt 输入: `{classId + classTier1Node + 6 attrs + village + background hints}`

新增的硬变量来自 Step 3 (属性) + Step 4 (职业) 的已完成状态。`background hints` 保留 Step 5 的玩家自由回答（PM 引导对话仍存在）。

PM 生成时多了：
- "战士 + 力量 14 + 敏捷 9" → 故事可写 "前哨战退役，重装步兵出身"
- "法师 + 智力 16 + 体质 8" → "体弱书生自学奥术"
- "无职业" 边界: classId 为空字符串, prompt 改为 "无职业冒险者, 自由身"

## §3 CharacterPanel 新布局（A+B 方案）

### 3.1 属性 Section 重构（问题 2）

**旧结构**:
```
[属性] section
  ├ AttributeRadar (200×170 SVG)
  ├ Vital Stats (HP/Level 2 行 chip)
  └ Attributes 文字 (6 行 label + 数字)
总高度: ~280px
```

**新结构**:
```
[属性] section
  ├ AttributeRadar (140×100 SVG, 等比缩小)
  └ 6 行紧凑 chip (3 列网格)
总高度: ~140px
```

**实施**: 复用 `AttributeRadar` 组件，传入 `width={140} height={100}` prop；`Attributes` section 改用 2 列 grid，每个 chip 显示 emoji + 名称 + 数值。

### 3.2 头部新增职业文字（问题 3）

**旧**:
```tsx
<div>{character.race}</div>
```

**新**:
```tsx
<div>
  种族：{character.race}，
  {character.classId
    ? <button onClick={() => setClassModalOpen(true)}>
        职业：{getClassName(character.classId)} ▼
      </button>
    : <span className="text-gray-500">职业：无职业</span>}
</div>
```

样式：职业文字用 `text-amber-400 underline cursor-pointer`（可点击时）或 `text-gray-500`（无职业时）。

### 3.3 技能区合并（问题 4）

**旧**: 独立 2 个 section
- `ClassSkillTreeView` (12 节点 4×3 网格)
- `技能` (character.skills.map → label)

**新**: 单 `SkillsSection` 组件，3 种 chip：
```typescript
type SkillChip = {
  key: string;
  type: 'origin' | 'classLearned' | 'classAvailable';
  label: string;          // "基础战斗 Lv.2" 或 "T1·1 剑术专精"
};

// origin: character.skills
// classLearned: character.classSkills.map(nodeId => getClass(classId).nodes.find(n => n.nodeId === nodeId))
// classAvailable: getClass(classId).nodes.filter(n => !classSkills.includes(n.nodeId) && n.unlockedByLevel <= level)
```

排序：`[...origin, ...classLearned, ...classAvailable]` 按 type 内顺序 (tier 升序 / level 升序)。

样式：
- `origin`: `bg-indigo-500/15 border-indigo-500/30 text-indigo-300`
- `classLearned`: `bg-emerald-500/15 border-emerald-500/30 text-emerald-300`
- `classAvailable`: `bg-amber-500/15 border-amber-500/30 text-amber-300` + 加锁图标（如果需更高级）

### 3.4 折叠次要内容 (A+B 策略)

| Section | 状态 | 说明 |
|---------|------|------|
| 头部 (姓名+种族职业) | 默认展开 |  |
| HP bar | 默认展开 |  |
| Level/EXP bar | 默认展开 |  |
| 属性 (雷达+文字) | **默认展开** (核心数据) |  |
| 状态 (7 项 chip) | 默认展开 | 横向排列 |
| 技能 (3 种 chip) | 默认展开 | 横向排列 |
| 声望 | `<details>` 折叠 |  |
| 装备 | `<details>` 折叠 |  |
| 货币 | `<details>` 折叠 |  |
| 背包 (前 6 件) | `<details>` 折叠 |  |
| 异常条件 | 默认展开 (有数据时) | |

## §4 职业技能树 Modal（新组件）

### 4.1 触发
- CharacterPanel 头部职业文字 `onClick={() => setClassModalOpen(true)}`
- 状态：`const [classModalOpen, setClassModalOpen] = useState(false)`

### 4.2 内容结构

```
[全屏覆盖, 90vw × 90vh 居中]
┌──────────────────────────────────────┐
│ [✕ 关闭]   ⚔️ 战士 技能树  [已学 1/12]│
├──────────────────────────────────────┤
│                                      │
│  [3 列 × 4 行 节点网格, 每格 100×100] │
│                                      │
│   T1·1       T1·2       T1·3         │
│   剑术专精    盾击       战吼         │
│   (已学✅)   (可学)    (Lv.2 解锁)   │
│                                      │
│   T2·1 ...                           │
│                                      │
├──────────────────────────────────────┤
│ 节点详情面板 (点击节点时显示):       │
│   剑术专精 (T1·1)                    │
│   描述: 剑系伤害 +10%                │
│   等级要求: Lv.1 (已达成)            │
│   状态: ✅ 已学                      │
└──────────────────────────────────────┘
```

### 4.3 节点状态
- **已学** (`classSkills.includes(nodeId)`): 绿色高亮 + 边框 + 角标
- **当前可学** (`unlockedByLevel <= level`): 灰白 + 边框
- **未解锁** (`unlockedByLevel > level`): 深灰 + 锁图标 + "需 Lv.X" 文字

### 4.4 关闭方式
- 右上 X 按钮
- Esc 键 (用 useEffect 监听)
- 点击遮罩 (z-index 容器 click)

### 4.5 文件
- 新建 `client/src/components/panels/CharacterPanel/ClassSkillTreeModal.tsx`
- props: `classId: string, isOpen: boolean, onClose: () => void`
- 数据源: `getClass(classId)` 从 `classRegistry` 取
- 复用: 风格仿 `GuildClassModal` 的全屏布局, 但内容是只读 (不像 GuildClassModal 有"选职业"按钮)

## §6 错误处理

| 场景 | 处理 |
|------|------|
| `finalizeCharacter` 名字/外貌生成失败 | 已 try/catch, fallback `useClassDefaultNames` |
| Modal 内 `getClass(classId)` 失败 | classId 为空时 Modal 不打开 (头部不可点击) |
| 技能合并时 `classId` 为空 | 跳过职业节点, 只显示 `origin` chip |
| 技能合并时 `classSkills` 为空数组 | 跳过 `classLearned`, 显示 `classAvailable` (假设有 classId) |
| Wizard 步骤 2 名字/外貌留空 | "AI 自动生成" 按钮必须可用, 走与 review step 同一条路径 |
