# v0.6.3 — 物品 Affix 池扩展 + 法杖/圣印记 + 装备效果接入战斗

> 继承自：v0.6.2 (commit `4b11963`, 统一 Ability + 战斗接入)
> 锁定日期：2026-06-09
> 后续：v0.6.4（学习 UI & 叙事）

---

## §0 背景

v0.6.2 建立了 8 元素抗性系统 (fire/ice/lightning/wind/earth/arcane/holy/shadow)，但：
1. affixPools 中只有 1 个抗性词条 (`arm_resist_1`, 火抗+20%)
2. 装备上的 `elemental_resist` 词条**未被汇总**到 combatant 的抗性中
3. 没有施法类武器 (法杖/圣印记)，法师和牧师只能用普通武器

v0.6.3 解决这三个缺口。

### 3.4 Affix 抽取时的子类过滤

扩展 `Affix` 接口：

```typescript
export interface Affix {
  readonly weight: number;
  readonly minQuality: ItemQuality;
  readonly effect: ItemEffect;
  /** 可选: 仅当物品 subCategory 匹配时才纳入候选 */
  readonly minSubCategory?: string;
}
```

`drawBuffs` / `rollDebuff` 中增加过滤：

```typescript
const candidates = AFFIX_POOLS[category].buffs.filter(a =>
  qualityAtLeast(quality, a.minQuality) &&
  (!a.minSubCategory || itemSubCategory === a.minSubCategory)
);
```

## §4 模块 C: 装备效果接入战斗

### 4.1 新增 `getEquipmentResistances()`

```typescript
// ActionResolver.ts 新增
export function getEquipmentResistances(
  equipped: Combatant['equipped'],
): Partial<ElementalResistances> {
  const result: Partial<ElementalResistances> = {};
  const slots = [equipped.weapon, equipped.armor, equipped.accessory];
  for (const item of slots) {
    if (!item?.effects) continue;
    for (const eff of item.effects) {
      if (eff.type === 'elemental_resist' && typeof eff.value === 'object' && eff.value !== null) {
        const v = eff.value as Record<string, unknown>;
        for (const [element, val] of Object.entries(v)) {
          if (typeof val === 'number') {
            result[element as keyof ElementalResistances] =
              (result[element as keyof ElementalResistances] ?? 0) + val;
          }
        }
      }
    }
  }
  return result;
}
```

### 4.2 新增 `getEquipmentMPBonus()`

```typescript
export function getEquipmentMPBonus(equipped: Combatant['equipped']): number {
  let bonus = 0;
  const slots = [equipped.weapon, equipped.armor, equipped.accessory];
  for (const item of slots) {
    if (!item?.effects) continue;
    for (const eff of item.effects) {
      if (eff.type === 'mp_bonus' && typeof eff.value === 'number') {
        bonus += eff.value;
      }
    }
  }
  return bonus;
}
```

### 4.3 战斗初始化合并装备抗性

在 `debugCombatStarter.ts` 和 `combatTools.ts` 的 combatant 构造处：

```typescript
// 合并装备抗性到 combatant
const equipResists = getEquipmentResistances(character.equipped);
const combatant: Combatant = {
  // ...
  elementalResistances: {
    ...character.elementalResistances,
    ...Object.fromEntries(
      Object.entries(equipResists).map(([k, v]) => [k, (character.elementalResistances[k] ?? 0) + v])
    ),
  },
  maxMp: character.maxMp + getEquipmentMPBonus(character.equipped),
  mp: character.mp + getEquipmentMPBonus(character.equipped),
};
```

### 4.4 战斗日志显示装备抗性

在战斗日志的门槛构成行中，如果装备贡献了抗性，额外标注：

```
  抗性: 7×(1-20/200) -1(抗性减免)=6 [含装备火抗+20]
```

## §5 数据流

```
characterStore.character
  ├── elementalResistances (基础)
  ├── equipped.weapon.effects → elemental_resist / mp_bonus / attribute_mod
  ├── equipped.armor.effects → elemental_resist / defense_bonus
  └── equipped.accessory.effects → elemental_resist / attribute_mod
        │
        ▼
  getEquipmentResistances(equipped) → 合并到 combatant.elementalResistances
  getEquipmentMPBonus(equipped) → 合并到 combatant.maxMp
  getEquipmentAttributeMods(equipped) → effectiveAttribute() (已有)
        │
        ▼
  ActionResolver.resolveAbilityDamage → applyResistance() → 最终伤害
```
