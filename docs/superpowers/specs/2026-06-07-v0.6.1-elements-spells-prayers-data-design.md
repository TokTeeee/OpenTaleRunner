## §0 背景

v0.5 完成了 4 职业 / 12 节点技能树 / 装备 affix 池 / 战斗系统等基础。LLM 在叙事中已经能提到 "法师施法" / "牧师祷告", 但**没有可执行的法术/祷告数据结构**, 也没有元素抗性系统。

### 2.2 能力描述（共享结构）

```typescript
export interface AbilityDescription {
  /** 战斗效果 1 行, e.g. "射出火球造成 1d6+INT_MOD 火属性伤害" */
  shortEffect: string;
  /** 50-80 字叙事风描述, 供 PM Engine 注入到 narrative, e.g.
   * "指尖聚起炽热的光点, 空气被灼得扭曲变形..." */

```

### 2.3 Spell（法术）

```typescript
export type SpellTarget = 'enemy' | 'ally' | 'self' | 'all_enemies';
export type SpellTier = 1 | 2 | 3;

export interface Spell {
  id: string;                          // 'spell_fire_bolt'
  name: string;                        // '火球术'
  school: 'magic';                     // 判别符
  element: MagicElement;
  tier: SpellTier;
  requirements: {
    /** 允许的职业, 包含 'any' (无职业冒险者也能学, v0.6.1 暂不开 any) */
    classes: Array<'mage' | 'any'>;
    minAttribute: { INT: number };
    minLevel: number;
  };
  cost: { ap: number; mp: number };
  target: SpellTarget;
  damageFormula: {
    dice: string;                      // '1d6' / '2d6+1'
    damageType: MagicElement;
    intScale: number;                  // INT 修正加成, 0.5 表示 floor((INT-10)/2) * 0.5
  };
  description: AbilityDescription;
}
```

### 2.4 Prayer（祷告）

```typescript
export type PrayerTarget = 'ally' | 'self' | 'all_allies' | 'enemy';
export type PrayerTier = 1 | 2 | 3;

export interface Prayer {
  id: string;                          // 'prayer_holy_heal'
  name: string;
  school: 'prayer';
  element: PrayerElement;
  tier: PrayerTier;
  requirements: {
    classes: Array<'cleric' | 'any'>;
    minAttribute: { WIS: number };
    minLevel: number;
  };
  cost: { ap: number; mp: number };
  target: PrayerTarget;
  effect: {
    healDice?: string;                 // '1d6+1'
    healWisScale?: number;             // 0.5 = (WIS-10)/2 * 0.5 加成
    applyBuff?: { ref: string; stacks: number; turns: number };
  };
  description: AbilityDescription;
}
```

**关键设计点**: 法术 = 伤害型（damageFormula）, 祷告 = 治疗/buff 型（healDice + applyBuff）。两个系统**伤害模型不同** — 反映 INT 元素攻击 vs WIS 神恩治愈/护佑的本质差异。用户确认接受此差异。

## §3 元素抗性公式

```typescript
// services/abilities/abilityUtils.ts (新建)

/**
 * 元素抗性 → 伤害乘数.
 * 公式: finalDamage = baseDamage * (1 - resistance / 100)
 *
 * 抗性 20  → 受 80% 伤害
 * 抗性 -50 → 受 150% 伤害
 * 抗性 100 → 免疫 (0 伤害)
 * 抗性 clamp 到 [-100, 100]
 */
export function resistanceMultiplier(resistance: number): number {
  const clamped = Math.max(-100, Math.min(100, resistance));
  return 1 - clamped / 100;
}
```

**v0.6.1 阶段**: 仅做纯函数 + 类型 + 默认 0 值。**不**接入 ActionResolver 公式（v0.6.2）;**不**接入物品 affix 池（v0.6.3）;**不**接入 buff（v0.6.4）。

## §5 学习校验

### 5.1 checkCanLearn 纯函数

```typescript
// services/abilities/learnAbility.ts

export interface LearnCheckInput {
  character: Pick<Character, 'classId' | 'level' | 'attributes'>;
  ability: Spell | Prayer;
}

export type LearnCheckResult =
  | { canLearn: true }
  | { canLearn: false; reason: 'class' | 'attribute' | 'level'; required: string };

export function checkCanLearn(input: LearnCheckInput): LearnCheckResult {
  const { character, ability } = input;
  const r = ability.requirements;

  // 1. 职业（允许 'any' 兜底 — v0.6.1 暂未启用, 但校验逻辑保留）
  const allowedClasses = r.classes;
  const classOk = allowedClasses.includes('any') || (character.classId !== null && allowedClasses.includes(character.classId as 'mage' | 'cleric'));
  if (!classOk) {
    return { canLearn: false, reason: 'class', required: allowedClasses.join(' 或 ') };
  }
  // 2. 属性（Spell 用 INT, Prayer 用 WIS — 编译期已收窄）
  if ('INT' in r.minAttribute) {
    if (character.attributes.INT < r.minAttribute.INT) {
      return { canLearn: false, reason: 'attribute', required: `INT ≥ ${r.minAttribute.INT}` };
    }
  } else if ('WIS' in r.minAttribute) {
    if (character.attributes.WIS < r.minAttribute.WIS) {
      return { canLearn: false, reason: 'attribute', required: `WIS ≥ ${r.minAttribute.WIS}` };
    }
  }
  // 3. 等级
  if (character.level < r.minLevel) {
    return { canLearn: false, reason: 'level', required: `等级 ≥ ${r.minLevel}` };
  }
  return { canLearn: true };
}
```

## §8 错误处理

| 场景 | 处理 |
|---|---|
| `getSpell(id)` 传入未知 id | 返 null（不抛错）, 调用方需 null check |
| `checkCanLearn` 角色无 classId | 校验时 `character.classId` 为 null, 任何非 'any' class 要求都失败 |
| `addLearnedAbility` 重复 id | skip + log warn, 不抛错 |
| `setResistance` 值越界 | clamp 到 [-100, 100], 不抛错 |
| 测试 reset 时漏清新字段 | 改 `utils/resetStores.ts`, 显式重置 `learnedAbilities=[]` + `elementalResistances=ZERO_RESISTANCES` |
