# 艾瑟兰大陆 —— 世界设定与故事主轴

---

## 一、世界概览

### 1.1 大陆名称：艾瑟兰 (Aeslan)

艾瑟兰大陆形如一片向东张开的龙翼，南北纵跨寒带至热带，西侧为浩瀚的无尽之海，东侧是传说中"沉没大陆"所在的迷雾之洋。

**大陆东端的黑曜石荒原上，矗立着一座直插云霄的通天巨塔。** 没有人知道它建于何时、由谁建造——它比任何已知文明都要古老。古代文献称它为**"世界之脊"(Worldspine)**，传说它是连接更高世界的通道。但数千年来，塔的入口被深埋于魔王的黑曜石王座之下，无人能够触及。

当前版本仅开放艾瑟兰本陆（第一个世界）。

### 1.2 历史纪元

| 纪元 | 年份 | 大事件 |
|------|------|--------|
| 创世纪元 | ? - 3000年前 | 诸神塑造世界，七大元素精灵诞生。**通天塔已存在**，无人知其来历 |
| 黄金纪元 | 3000年前 - 1200年前 | 古代魔法文明鼎盛，浮空城与地下遗迹的时代。古代法师曾试图解析通天塔的力量 |
| 灾厄纪元 | 1200年前 - 800年前 | **第一次魔王战争**：深渊裂隙开启，魔物席卷大陆。通天塔被魔气浸染，入口消失 |
| 英雄纪元 | 800年前 - 10年前 | 七英雄封印深渊，建立七王国，大陆恢复和平。通天塔仍深埋地下 |
| 暗潮纪元 | 10年前 - 现在 | **光芒英雄阿尔德里克的堕落**，第二次魔王战争的前夜。他选择黑曜石王座为据点，正是**因为那里位于通天塔的正上方** |

### 1.3 当前时代：暗潮纪元

10年前，被誉为"光芒英雄"的圣骑士**阿尔德里克·晨星**在讨伐深渊残党的远征中失踪。当他归来时，已化身新的魔王。没有人知道他在深渊中经历了什么——他不再是拯救人类的英雄，而是统率魔物大军的魔王。他在大陆东端的**黑曜石王座**建立了新的魔王城，旧日的魔物从地底苏醒，向他的旗帜靠拢。

自那时起，大陆各地开始出现小型魔物潮、村庄遭袭、商路中断。但魔王的大规模入侵尚未开始。大陆的七个王国正抓紧时间备战，同时向冒险者公会发出悬赏，招募一切愿意挺身而出的战士。

**游戏开始时**，玩家就在这个时间点进入世界。

## 三、故事主轴与里程碑系统

### 3.1 核心故事线

```
序章: 暗潮初现
  │
  ▼
第一章: 七国的备战 ────── 玩家自由探索、成长、积累力量
  │
  ▼
【里程碑 M1】魔潮涌动 ─── 各地出现大规模魔物潮，区域攻防战开启
  │
  ▼
第二章: 战火四起 ────── 魔王军正式入侵，魔将登场
  │
  ▼
【里程碑 M2】四魔将降临 ─ 四个区域遭遇魔将亲自率军进攻，大攻防战
  │
  ▼
第三章: 反攻的狼烟 ──── 人类联合军集结，反攻魔王领地
  │
  ▼
【里程碑 M3】黑曜石总攻 ─ 最终攻防战，决定故事结局
  │
  ▼
终章: 结局分岐
  ├── 大胜利：魔王被击败，领地收复。通天塔的封印被打破，入口显现。
  │    通往第二世界的门已开启，编年史记载了英雄之名
  ├── 惨胜：魔王被击败但代价沉重。通天塔在余震中半开，入口不稳定
  ├── 惜败：魔王重伤撤退，塔的封印出现裂痕但未完全打开
  └── 大败：魔王军占领全大陆，世界进入黑暗时代。通天塔被更深地封印
       → 开启"抵抗篇"新章，玩家在沦陷区持续抗争
```

### 3.2 里程碑触发机制

每个里程碑不按固定时间触发，而是按**所有玩家在服务器上的累计贡献值**。

| 里程碑 | 触发条件 | 触发后发生什么 |
|--------|----------|---------------|
| **M0: 序章** | 至少50个角色完成出身设定，且分布在至少3个区域 | 各区域开始出现小型魔物目击事件，冒险者公会发布第一个全服公告 |
| **M1: 魔潮涌动** | 全服累计完成2000次冒险委托 或 任意区域贡献值达到500 | 各区域同时爆发魔物潮（区域攻防战开启），魔王正式向人类宣战。魔将开始在故事中出现 |
| **M2: 四魔将降临** | 全服累计击败魔物达到10000体 且 至少3个区域贡献值达到1000 | 四魔将各自率领大军进攻随机四个区域，同时发生四场大攻防战。需要玩家集中力量防守 |
| **M3: 黑曜石总攻** | 四魔将中至少2位被击败 且 总贡献值达到50000 | 人类联合军集结进攻魔王领地。所有区域玩家可参与最终战役。战役持续72小时现实时间 |

**贡献值（Contribution Point）获取方式**：

| 行为 | 获得CP |
|------|--------|
| 完成冒险委托 | 1-5 CP |
| 讨伐魔物 | 视魔物等级获取 |
| 探索地下城并安全返回 | 视探索深度获取 |
| 参与区域攻防战 | 大量CP（战斗表现相关） |
| 为区域防御做出后勤贡献（锻造武器、提供物资） | 少量CP |
| 编年史日志中记录了重要发现/事件 | 额外的发现CP |

### 3.3 结局分岐条件

| 结局 | 条件 | 通天塔状态 | 对第二世界的影响 |
|------|------|-----------|-----------------|
| **大胜利** | M3攻防战中，72小时内总贡献值超过魔王耐久度，且全服参与玩家数 > 100 | **封印解除，塔门完全开启** | 第二世界是一片被高天之光庇佑的领域，玩家进入一个"光与秩序"的更高世界 |
| **惨胜** | 超过72小时才达成，或参与玩家不足100人但最终击败 | **塔门半开，部分区域可探索但通道不稳定** | 第二世界是一个"混沌与新生"的世界——秩序尚未完全建立，玩家需要同时面对第一世界的战后重建和第二世界的未知 |
| **惜败** | 72小时内未达成目标贡献值，但差值在20%以内 | **封印出现裂痕，仅少数玩家可冒险穿入** | 第二世界是"险境与试炼"——魔王虽未死但力量大损，塔的另一端是严酷的试炼场，只有最强玩家能踏足 |
| **大败** | 贡献值差距超过20% | **通天塔被更深封印，入口彻底关闭** | 第二世界无法直接进入。玩家在沦陷区继续"抵抗篇"，寻找重新打开塔的方法。塔的另一端变成了"深渊倒映"——一个被黑暗力量扭曲的堕落世界 |

**核心理念**：玩家的集体行为不仅决定第一世界的命运，也决定了第二世界的色调。
- 大胜利 → 第二世界是**明亮的、有秩序的、更高层级的文明**
- 大败 → 第二世界是**黑暗的、扭曲的、需要救赎的世界**
- 中间态 → 第二世界是**混沌的、待开拓的、有无限可能的世界**

无论哪种结局，第二世界的**地形、种族、文化、魔法规则**都可以完全不同——因为两个世界在过去数千年从未通信。

## 四、通天塔 —— 多世界的枢纽

### 4.1 通天塔的本质

通天塔（Worldspine）不是一座普通的建筑。它是**连接多个世界的轴心**，一种超越当前文明理解的存在。

| 属性 | 描述 |
|------|------|
| **高度** | 无法测量。从艾瑟兰地面拔起后，穿透云层，消失在肉眼可见的范围之外 |
| **材质** | 类似于黑曜石但更致密，表面铭刻着不属于任何已知文明的发光符文 |
| **年代** | 比创世纪元更古老。在诸神塑造世界之前就已存在 |
| **已知入口** | 目前唯一已知的入口位于艾瑟兰大陆，被黑曜石王座压在地表之下 |
| **内部结构** | 据古代文献残片记载，塔内部不是楼梯，而是一种"世界之间的折叠空间"——每登上一层，就是一个全新的世界 |

### 4.2 多世界模型

```
┌─────────────────────────────────────────────┐
│                 未知的世界...                 │
│                     ▲                       │
│              ┌──────┴──────┐                │
│              │   第三世界   │ ← 击败第二世界   │
│              │   (未来)     │    的魔王后开放  │
│              └──────┬──────┘                │
│                     ▲                       │
│              ┌──────┴──────┐                │
│              │   第二世界   │ ← 击败第一世界   │
│              │   (V2)      │    的魔王后开放  │
│              └──────┬──────┘                │
│                     ▲                       │
│              ┌──────┴──────┐                │
│              │ 第一世界     │ ← 当前版本       │
│              │ 艾瑟兰大陆   │                 │
│              └─────────────┘                │
└─────────────────────────────────────────────┘
```

**核心规则**：
1. 每个世界之间存在**千年隔绝**——没有通信、没有贸易、没有移民
2. 击败当前世界的魔王 → 通天塔开启通往上一层的通道
3. 每个世界的**世界观、地形、种族、文明、魔法/技术体系可以完全不同**
4. 新玩家总是出生在已开放的最高世界（或任选已开放的世界游玩）
5. 老玩家可以自由选择留在当前世界还是向上探索

### 4.3 为什么魔王总是盘踞塔的入口

这是通天塔最深的谜团。每个世界的魔王——不论其出身、种族、时代——最终都会**本能地被塔吸引**，并将其作为据点。古代贤者提出了几种假说：

| 假说 | 内容 |
|------|------|
| **封印假说** | 魔王并非占领塔，而是**被塔封印**。塔是诸神留下的监狱，魔王被束缚在塔基，无法离开其所在的世界 |
| **力量源泉假说** | 塔散发出某种原始能量，魔王需要靠近它来维持力量。击败魔王 = 切断其与塔的连接 |
| **守护者假说** | 魔王是塔的"考验者"。只有击败守护者，证明一个世界的文明已足够成熟，才能被允许进入更高的世界 |
| **深渊倒映假说** | 塔不仅是向上通往更高世界的通道，同时也向下连接着深渊。魔王是为阻止深渊之物爬出而存在的"守门人"——阿尔德里克可能正是理解了这一点才选择堕落 |

**真相可能在后续世界中逐步揭示。** 每个世界可能提供一块拼图。

### 4.4 未来世界预留概念

| 世界 | 暂定主题 | 触发条件 | 世界观方向（示例） |
|------|---------|----------|-------------------|
| **第一世界** | 日式RPG奇幻 | 当前版本 | 人类七王国、剑与魔法、堕落英雄魔王 |
| **第二世界** | 由结局决定 | M3完成后 | 大胜利→"辉光大陆"（高天文明、光之种族）<br>大败→"倒悬深渊"（扭曲世界、生存恐怖） |
| **第三世界** | 待定 | 第二世界魔王被击败 | 预想：蒸汽朋克废土 / 东方仙侠 / 赛博魔法混合 |
| **第四世界及以后** | 待定 | 逐层解锁 | 每次新世界以1-2年现实时间为周期推出 |

### 4.5 跨世界规则

- **角色可携带装备和技能**跨越世界（但新世界的材料和规则可能使旧装备不再最优）
- **角色等级和属性保留**（但每个世界可能有自己的"本地成长系统"作为新进度维度）
- **编年史在世界间是独立的**（每个世界有自己的编年史卷册，便于新玩家加入第二世界时不必了解第一世界的全部历史）
- **幽灵NPC不通世界**（第一世界的幽灵NPC不会出现在第二世界——除非某个玩家在两个世界都留下了足迹）

## 五、藏宝洞窟与地下城设计

### 4.1 分级系统

| 等级 | 推荐角色强度 | 示例 |
|------|-------------|------|
| **新手 (Lv1-3)** | 初始角色可挑战 | 城镇下水道、小型哥布林巢穴 |
| **初阶 (Lv4-7)** | 需要基础装备+1-2技能 | 废弃矿坑、森林中的盗贼要塞 |
| **中阶 (Lv8-12)** | 需要中级装备+技能组合 | 古代神殿遗迹、龙巢浅层 |
| **高阶 (Lv13-16)** | 需要高级装备+团队配合 | 精灵王陵、深渊裂隙入口 |
| **传说 (Lv17-20)** | 接近满级角色 | 黑曜石王座、四魔将堡垒 |

### 4.2 地下城类型

| 类型 | 特征 | 奖励倾向 |
|------|------|----------|
| **遗迹探索型** | 古代文明的废墟，以解谜、考古为主 | 古代魔法、失落技艺 |
| **魔物巢穴型** | 魔物聚居地，以战斗为主 | 材料、装备掉落 |
| **迷宫挑战型** | 多层迷宫，需要找路 | 宝箱、稀有道具 |
| **BOSS挑战型** | 单一的强敌战斗 | 专属装备、传奇武器 |
| **遗迹故事型** | 包含过去历史的叙事碎片 | 故事线索、世界真相 |

### 4.3 藏宝洞窟随机生成规则

每个区域周期性刷新"藏宝洞窟"——由服务器算法随机生成（非LLM）：

- 刷新频率：每个区域每24现实小时生成1-2个
- 位置：在区域坐标范围内随机散布
- 内容：基于模板池随机组合（地形模板×3 + 魔物模板×4 + 宝藏模板×5 + 陷阱模板×3）
- 共享性：所有玩家均可探索，但**宝藏只掉落给第一个发现者**（先到先得）
- 洞窟在被探索后24小时内消失

## 六、区域攻防战设计

### 5.1 触发条件

攻防战分为三种级别：

| 级别 | 触发条件 | 规模 |
|------|----------|------|
| **小型魔物潮** | 随机触发（区域活跃玩家越多概率越高） | 单区域，持续6现实小时 |
| **大型魔物潮** | 里程碑M1之后，随机触发 | 单区域，持续24现实小时 |
| **魔将攻城战** | 里程碑M2触发，四魔将各攻一区 | 四区域同时，持续48现实小时 |
| **最终战役** | 里程碑M3触发 | 魔王领地，持续72现实小时 |

### 5.2 集体贡献制运作

```
攻防战开始 → 服务器创建"战场实例"
      │
      ▼
玩家A在区域内 → 被通知攻防战正在进行
      │
      ▼
┌─────────────────────────────────────┐
│  玩家可选择参与方式:                  │
│  ① 正面作战: 与魔物军队交战          │
│  ② 防御工事: 加固城墙/设置陷阱       │
│  ③ 后勤支援: 提供物资/治疗伤员       │
│  ④ 特殊行动: 潜入后方破坏敌军指挥    │
│  ⑤ 自由行动: 自定义输入任何行为      │
└───────────┬─────────────────────────┘
            ▼
┌─────────────────────────────────────┐
│  玩家行为 → 本地PM评估 → 贡献值计算  │
│  · 正面作战: 基于角色战斗力的CP      │
│  · 特殊行动: 基于技能+判定的CP       │
│  · 后勤: 基于提供物资价值的CP        │
└───────────┬─────────────────────────┘
            ▼
上传编年史日志 → 服务器结算

服务器定期结算（每30分钟）:
  · 汇总该区域所有玩家的贡献值
  · 对比防御阈值
    ├── 达标: 显示"战线稳固" / 防御推进
    └── 未达标: 防线后退，部分区域被占领
  · 更新区域状态 → 影响后续剧情
```

### 5.3 离线玩家的处理

- 攻防战开始时，系统通过通知提醒在线玩家
- 离线玩家下次上线时会被告知攻防战进展（"编年史通知"）
- 如果攻防战已结束，离线玩家可以阅读战报，但无法参与已完成的历史战役
- **幽灵NPC机制**：如果玩家A在攻防战期间在线并参与，其幽灵NPC会留在战场上继续"战斗"一段时间，供后续上线的玩家B在战场上遇见

### 5.4 攻防战奖励

| 结果 | 奖励 |
|------|------|
| 防区守住 | 所有参与者获得区域声望+稀有战利品抽奖权 |
| 防线后退 | 参与者获得"坚守者"称号，有减弱的奖励 |
| 区域沦陷 | 该区域玩家获得"流亡者"背景标签，新的主线任务——收复家园 |
| MVP玩家 | 攻防战中贡献最高的玩家被编年史记录为"战场英雄" |

## 七、核心NPC与势力关系

### 7.1 NPC角色设计原则

艾瑟兰大陆上的每个NPC都具有完整的角色卡——不仅是对话工具，而是有血有肉的独立个体。NPC设计遵循以下原则：

| 原则 | 说明 |
|------|------|
| **完整人物卡** | NPC拥有6维属性（STR/DEX/CON/INT/WIS/CHA）、技能组（含熟练度Lv）、背景故事、性格标签、动机 |
| **可成长** | 关键NPC的技能可以随剧情推进而成长（如布洛克学会新的锻造配方、卡珊德拉恢复圣骑士技能） |
| **可社交** | 玩家与NPC的关系由好感度（-100~100）和5级关系度（陌生人→相识→朋友→密友→盟友）量化 |
| **有秘密** | 每个NPC有若干"秘密"，好感度达标或特定条件触发时逐条揭示，推动隐藏剧情 |
| **可组队** | 某些NPC可以被招募为临时队友（`canBeRecruited=true`），参与战斗和探索 |

### 7.2 NPC分类与生成策略

| 类型 | 来源 | 数据量 | 存储位置 | 说明 |
|------|------|--------|----------|------|
| **模板NPC** | 服务端下发模板（~20个基础类型） | 每个区域50-200个（程序生成） | 服务端分发，客户端按需生成 | 商人/铁匠/旅店老板/守卫/治疗师/学者/猎人/农夫/祭司/炼金术士等。每个区域的具体NPC由客户端基于模板+区域文化随机生成名字/外貌/性格。 |
| **客户端专属NPC** | PM在游戏过程中动态创建 | 每个玩家50-200个 | 客户端创建→登记到服务端 | 出身背景中的同村人、家族成员、冒险途中结识的人。初始为客户端独占，登记到服务端后不共享给其他玩家。 |
| **升格NPC** | 服务端检测到某NPC被多个玩家频繁交互 | 动态增长 | 服务端标记→广播到所有客户端 | 任何模板NPC或专属NPC都可能因玩家集体行为被升格。升格后获得完整背景故事、新技能、区域影响力。 |
| **作者手写NPC** | 世界作者手工添加 | 10-50个 | 服务端npc_templates.json的author_npcs列表 | 可选项。作者可以为世界添加具有完整故事的人物。这些NPC与模板NPC没有本质区别。 |

**核心设计原则：NPC没有预设的"关键/非关键"之分——是玩家的集体行为赋予了NPC重要性。**

### 7.3 NPC升格机制

| 条件 | 触发 | 效果 |
|------|------|------|
| 5个不相关玩家与该NPC交互 | 服务端标记为"受关注" | 该NPC开始在其他玩家的区域中以"小有名气"的标签出现 |
| 单一玩家交互 ≥ 20次 或 好感 ≥ 80 | 客户端标记可升格 | 服务端检查后为该NPC生成详细背景、解锁专属任务 |
| NPC在3个以上世界日编年史中被提及 | 服务端生成为"区域名人" | 生成扩展背景故事、增加技能、可以被招募 |
| NPC行为对区域状态产生实质影响 | 服务端登记为"区域固定NPC" | 永久出现在该区域，即使原玩家不在线 |
| NPC对主线产生不可忽视的影响 | 服务端加入世界编年史常驻角色 | 全服已知，成为世界历史的一部分 |

好感度是整个社交系统的核心，直接影响玩家与NPC的交互深度。

| 关系度 | 好感范围 | 交互效果 |
|--------|----------|----------|
| 陌生人 (stranger) | -100 ~ 4 | NPC不会主动提供帮助；高价交易；不会透露任何秘密 |
| 相识 (acquaintance) | 5 ~ 24 | NPC记得玩家的名字和身份；正常交易；可能给基础任务 |
| 朋友 (friend) | 25 ~ 49 | NPC更愿意分享信息；偶尔提供折扣或优先任务；可能透露1个秘密 |
| 密友 (close) | 50 ~ 79 | NPC主动提供帮助；最优交易条件；透露深层秘密；可考虑组队 |
| 盟友 (ally) | 80 ~ 100 | NPC与玩家完全信任；愿意冒险陪同；提供独一无二的服务（如专属锻造、特殊术式训练）；全部秘密开放 |

### 7.4 好感度变化规则

| 行为 | 好感变化 |
|------|----------|
| 帮助NPC完成任务 | +5 ~ +20（视任务重要性） |
| 在战斗中保护NPC | +10 |
| 赠送稀有物品 | +5 ~ +15（视物品价值） |
| 与NPC所属势力友好互动 | +2 ~ +5 |
| 欺骗或背叛NPC | -15 ~ -30 |
| 在NPC面前伤害其在意的人 | -20 ~ -40 |
| 长期不与NPC互动（超过30游戏日） | 每10天 -2（最低降至"相识"下限） |
| 揭示NPC的秘密（未经其同意） | -25 |
| 帮助NPC实现个人动机 | +20 ~ +30 |

### 7.5 组队NPC规则

- `canBeRecruited=true` + 好感度 ≥ 60 → 可以邀请NPC作为临时队友
- 组队后NPC在编年史中以"队友"身份记录
- 队友NPC参与战斗时使用自己的属性+技能进行独立判定
- 队友NPC在战斗中受伤会影响好感（如果玩家保护不力可能降低好感）
- 组队NPC在特定条件达成后可"毕业"——留在某个城镇，提供永久服务

### 7.6 关键NPC简表

| NPC | 身份 | 位置 | 角色 | 可组队 | 可成长 | 隐藏剧情 |
|-----|------|------|------|--------|--------|----------|
| **艾蕾娜·晨星** | 光辉王国女王 | 光辉城 | 主线引导者 | 否 | 是 | 她知道阿尔德里克堕落前调查过通天塔 |
| **老巴托克** | 冒险者公会会长 | 光辉城 | 新手引导 | 否 | 否 | 知道霍格失踪前最后造访地 |
| **赫卡特** | 魔法学院首席 | 光辉城 | 术式导师 | 否 | 否 | 远征队合影、深渊研究 |
| **莉安娜** | 精灵遗迹守护者 | 苍翠之都 | 真相揭示者 | 否 | 是 | 持有阿尔德里克记忆水晶 |
| **布洛克** | 锻冶公会首席 | 炉心城 | 装备锻造 | 否 | 是 | 弟弟格鲁姆加入魔王军的真相 |
| **格罗姆** | 北境部落联合首领 | 霜脊堡 | 隐藏历史 | 否 | 否 | 知道第七位英雄的名字 |
| **伊莎贝拉** | 航海商会船队统领 | 潮汐港 | 航海探索 | 否 | 否 | 阿尔德里克沉船位置 |
| **卡珊德拉** | 四魔将·悲叹之刃 | 魔王领地 | 可救赎魔将 | **是**（救赎后） | 是 | 可被说服背叛魔王 |
| **阿尔德里克·晨星** | 魔王/堕落英雄 | 黑曜石王座 | 最终Boss/隐藏救赎 | 否 | 否 | 从未真正堕落——他在镇压深渊 |

### 7.7 势力好感度系统

每个势力对每个玩家角色的态度分为：

| 态度等级 | 数值范围 | 效果 |
|----------|----------|------|
| 敌对 | -100 ~ -50 | 会被该势力NPC攻击，无法进入该势力领地 |
| 冷淡 | -49 ~ -10 | 无法接该势力的高级委托，商店价格上浮 |
| 中立 | -9 ~ 20 | 基本服务可用 |
| 友好 | 21 ~ 60 | 可以获得该势力的特殊委托和独家商品 |
| 崇敬 | 61 ~ 100 | 可以在该势力获得专属称号、特殊技能训练 |

## 八、编年史中的故事叙事风格

### 7.1 叙事口吻

世界编年史以**史官口吻**撰写，风格参考日式RPG的开场旁白或《火焰纹章》式的叙事：

> **世界日第132天 · 暗潮纪元**
>
> 铁脊山脉的矿工们永远不会忘记这一天。当他们挖穿古老的岩层时，等待他们的不是矿石，而是沉睡了千年的炎龙莫德雷德。炉心城在一夜之间陷入火海。
>
> 冒险者"雷格·铁锤"带领十七名矿工穿越燃烧的矿道，成功疏散了三百名平民。他的名字被刻在了炉心城的英雄碑上——
>

## 十、事件系统

### 10.1 设计理念

世界上发生的所有重要事情都由"事件模板"预先定义（服务端根据故事书自动生成），客户端PM在实际游玩中将这些模板适配为具体场景让玩家经历。事件之间的关系是网状的——可能有复杂的前置依赖、因果连锁、跨区域联动。

事件的本质是**编年史的骨架**——故事书提供世界框架，事件模板填充具体情节，玩家行为赋予血肉。

### 10.2 事件分级

| 等级 | 名称 | 数量（V1） | 示例 |
|------|------|-----------|------|
| **Major** | 重大事件 | 5-10 | 四魔将降临、魔王宣战、通天塔开启 |
| **Late** | 后期事件 | 10-20 | 魔将的个人故事线、真相碎片揭示 |
| **Mid** | 中期事件 | 20-50 | 派系冲突升级、区域间联动事件 |
| **Early** | 前期事件 | 30-80 | NPC初遇、小型魔物目击、古代遗迹发现 |
| **Minor** | 微事件 | 50-200 | PM可随时适配的环境遭遇、天气突变、NPC偶遇 |

V1 总计约 **100-300 个事件模板**，由服务端基于区域设定+故事线程序化生成。

### 10.3 事件触发条件

| 条件类型 | 说明 |
|----------|------|
| **world_day_X** | 世界日达到特定天数后解锁 |
| **player_in_region** | 玩家位于特定区域 |
| **npc_met** | 玩家已认识特定NPC |
| **events_completed** | 前置事件已完成 |
| **pm_adaptive** | PM可以主动适配，不受其他条件限制（仅微事件/早期事件） |
| **probability** | 随机概率触发（用于营造世界"活"的感觉） |
| **faction_attitude** | 玩家与某势力好感度达标 |

### 10.4 多玩家协作机制

当客户端PM准备触发某个事件时：
1. **先向服务端确认**该事件模板是否已被人触发
2. **未被触发** → 服务端创建事件实例，客户端PM生成场景，向服务端描述"事件开展计划"
3. **已被触发** → 玩家从另一个视角参与（协助主角、调查侧面线索、提供后勤支持），完成后双方叙事由服务端合并

### 10.5 事件在编年史中的呈现

每个事件完成后，其实际叙事被记录为编年史条目。事件的标题和摘要出现在看板上：谁发现了、当前进展如何、是否已完成。这使得所有玩家都能看到世界的"正在发生什么"。

## 五、规划

> 本世界设定文档主要描述世界观层（地理 / 历史 / NPC / 区域 / 主线 / 攻城战），不涉及运行时配置。运行时配置字段在故事书 `storybook.json` 顶层定义：
>
> - **`rules_for_pm`** — PM 决策规则（按章节/区域向 PM 注入的硬性约束，例如"不要在王都平原生成 7 级以上的敌对 NPC"）
> - **`output_schemas`** — GM 输出 JSON 的结构定义（PMEngine 解析 `consequences` / `narrative` / `choices` 的 schema 描述）
> - **`behavior_configs`** — NPC 行为配置（每个 NPC 模板的昼夜行动映射，被 `NPCBehaviorScheduler` 读取）
>
> 这三个字段**不在本设定文档范围内**，详见 [故事书 Schema 与替换指南](故事书Schema与替换指南.md) 的"runtime 配置字段"小节。

当前艾瑟兰大陆已拥有跨越五个纪元的宏大历史、七片风格迥异的区域、从序章到总攻的四阶段里程碑主线、以 Worldspine Tower 为轴心的多世界模型、区域攻城战的集体贡献制体系，以及 NPC 关系与派系交织的社会生态。

在叙事深度上，期望进一步扩展第四纪元的剧情细节，让黄金与灾厄交替的年代展现更多被遗忘的故事。同时开拓新的地理版图，让冒险者能够踏足北方冻土与南方群岛这些尚未被描绘的疆域。NPC 关系系统也将向更丰富的维度延伸——浪漫羁绊、宿敌对立、师徒传承等深层关系将赋予社交系统更厚重的情感表达。

Worldspine Tower 的第二世界将是世界设定的重要里程碑——一个因玩家集体选择而拥有不同色调的新世界将完整实现。区域将不再是静态的舞台，战争、瘟疫与繁荣会真实地重塑地图面貌。社区共创世界观的通道也将开启，让玩家的想象力汇入艾瑟兰的血脉之中。

更远的未来，期望实现多世界并行运行——玩家可以在不同世界间自由迁移，每个世界拥有独立的编年史与终局事件。世界的命运将不止于一次击败魔王的瞬间，而是在持续演进中书写属于所有冒险者的史诗。
